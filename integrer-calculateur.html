Intégrer le calculateur de taxe d’aménagement sur votre site

Vous êtes pisciniste, paysagiste, constructeur, agent immobilier, ou vous tenez le site d’une commune ou un blog sur la maison ? Vous pouvez afficher gratuitement sur votre site notre calculateur de taxe d’aménagement. Il couvre les 460 communes de Loire-Atlantique et de Vendée, pour une piscine comme pour une construction.

Le calculateur tel qu’il s’affichera

Le code à copier

Collez ce code dans une page de votre site, à l’endroit où le calculateur doit apparaître. Il fonctionne sur WordPress (bloc « HTML personnalisé ») et sur tout site qui accepte du code HTML.

Ce qu’il faut savoir

  • C’est gratuit, sans inscription et sans publicité.
  • Aucune donnée n’est envoyée : le calcul se fait dans le navigateur du visiteur. Le calculateur intégré ne dépose aucun cookie et ne mesure pas l’audience.
  • Les taux sont tenus à jour par nos soins, à partir des délibérations publiées par la DGFiP. Vous n’avez rien à modifier.
  • Merci de garder la ligne « Calculateur fourni par Extérieur Clair » avec son lien : c’est la seule contrepartie.

Les limites du calcul

Le montant affiché est une estimation. Le montant définitif est calculé par l’administration, et certaines communes appliquent des taux différents selon les secteurs. La méthode complète est expliquée sur la page taxe d’aménagement.

Une question ?

Écrivez à contact@gagnerdutemps.fr : nous pouvons adapter la hauteur du cadre ou vous aider à l’installer.

EC

Extérieur Clair — Ce guide est rédigé à partir des fiches officielles (service-public, impôts, BOFiP, préfectures) et des prix publiés, en croisant plusieurs sources chaque fois que possible et en signalant les fourchettes qui n’en ont qu’une. Ce site n’est pas artisan. Pour votre projet, la mairie (urbanisme) et les professionnels qui établissent vos devis restent les références. La méthode.
